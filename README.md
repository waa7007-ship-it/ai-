## Resonance — 음악 반응형 오디오비주얼 퍼포먼스

`index.html` 하나로 동작하는 실시간 비주얼라이저입니다. 음악의 박자와 주파수 대역을 분석해 색과 형태를 바꿉니다.

### 실행

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

`index.html`을 브라우저로 바로 열어도 데모와 파일 재생은 동작합니다. 마이크 입력은 `localhost` 또는 HTTPS에서만 허용됩니다.

### 소리 입력

| 입력 | 설명 |
| --- | --- |
| 데모 트랙 | Web Audio로 합성한 124 BPM 루프 (Intro → Build → Drop → Breakdown, 8마디마다 전환) |
| 오디오 파일 | `파일 열기` 버튼 또는 화면에 끌어다 놓기 (mp3, wav, ogg, m4a 등) |
| 마이크 | 실시간 공연·DJ 셋 입력용. 분석만 하고 스피커로 다시 내보내지 않음 |

### 음악 → 시각 매핑

| 분석 값 | 시각 반응 |
| --- | --- |
| 박 감지 (40–150 Hz 에너지 급증) | 입자 폭발, 화면 섬광, 색상 이동, 터널 링 생성. 8박마다 대칭 수 변경, `자동 전환`을 켜면 32박마다 장면 전환 (기본은 꺼짐) |
| SUB / LOW (20–250 Hz) | 중심 형태의 크기와 맥동, 터널 속도 |
| MID (250 Hz–2 kHz) | 윤곽의 굴곡, 회전 속도 |
| HIGH / AIR (2 kHz 이상) | 선 굵기, 반짝이는 입자, 별 흐름 |
| 스펙트럼 중심 주파수 | 기본 색상. 밝은 소리일수록 차가운 색 |
| 로그 스펙트럼 128밴드 | Bloom 꽃잎 모양, Tunnel 방사선 |
| 파형 | Orbit의 원형 오실로스코프와 대역별 리본 |

BPM은 박 간격의 중앙값으로 추정합니다.

### 기본 장면: Ring

공연의 기준은 얇은 원 하나입니다. 조용하면 가는 원만 남고, 소리가 들어오면 원에서 선이 자라 나와 원과 선 사이가 색으로 채워집니다. 원, 박자에 따른 부풂, 주파수에 따라 움직이는 선이 하나로 이어진 형태입니다.

- 원을 따라 주파수가 배치됩니다. 위쪽이 가장 낮은 음이고 좌우로 내려갈수록 높아져 아래쪽이 가장 높은 음입니다.
- **저음 (위쪽)**: 넓고 부드럽게 크게 부풀어 오릅니다.
- **중음 (옆부분)**: 원 전체에 잔물결이 생깁니다.
- **고음 (아래쪽)**: 잘고 날카로운 결로 움직입니다.
- **박자**: 원 자체가 부풀고, 그 위의 선도 함께 밀려납니다.
- 원 안쪽은 전체 음량에 따라 은은하게 밝아집니다.

### 장면과 단축키

- **1 Ring**: 위에서 설명한 기본 장면
- **2 Bloom**: 스펙트럼을 대칭 꽃잎으로 펼친 형태와 숨 쉬는 중심
- **3 Tunnel**: 박마다 생겨 다가오는 다각형 링과 스펙트럼 방사선
- **4 Orbit**: 원형 오실로스코프, 대역별 리본, 별 흐름

`Space` 재생/정지 · `1–4` 장면 · `A` 자동 전환 · `H` 화면 정리(무대용) · `F` 전체화면. 휴대폰에서는 화면을 탭하면 컨트롤이 숨겨집니다.

`prefers-reduced-motion` 설정을 켜면 섬광을 끄고 움직임을 줄입니다.
