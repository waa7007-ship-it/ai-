# 영어 단어 카드

성인 수준 영어 단어 50개를 카드로 외우는 웹앱이에요. 휴대폰 홈 화면에 설치해서 앱처럼 쓸 수 있어요(PWA).

## 파일 구성
| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 본체 (화면, 단어, 기능 모두) |
| `manifest.webmanifest` | 앱 이름·아이콘·색 등 "설치용 정보" |
| `sw.js` | 서비스 워커: 인터넷이 꺼져 있어도 열리게 해 줌 |
| `icons/` | 앱 아이콘 (`icon.svg`가 원본 그림) |

## 수정할 때 꼭 기억할 것
`index.html`을 고친 뒤에는 `sw.js` 맨 위의 `CACHE_NAME` 숫자를 하나 올려 주세요. (`wordcards-v1` → `wordcards-v2`)
그래야 이미 설치한 휴대폰 앱도 새 버전으로 바뀌어요.
