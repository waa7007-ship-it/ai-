# 영어 단어 학습

난이도(하/중/상)별 영어 단어를 카드로 외우는 웹앱이에요. 휴대폰 홈 화면에 설치해서 앱처럼 쓸 수 있어요(PWA).

## 파일 구성
| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 본체 (화면과 기능) |
| `words-easy.js` | 단어장 **하** – 중·고등 기초, 일상생활 단어 |
| `words-medium.js` | 단어장 **중** – 수능·토익, 뉴스·직장 단어 |
| `words-hard.js` | 단어장 **상** – 토플·텝스, 학술·전문 단어 |
| `manifest.webmanifest` | 앱 이름·아이콘·색 등 "설치용 정보" |
| `sw.js` | 서비스 워커: 인터넷이 꺼져 있어도 열리게 해 줌 |
| `icons/` | 앱 아이콘 (`icon.svg`가 원본 그림) |

## 단어 추가하는 법
1. 난이도에 맞는 `words-○○.js` 파일을 열어요.
2. `{ ... },` 덩어리 하나를 복사해서 목록 맨 아래(마지막 `];` 바로 위)에 붙여 넣고 내용만 바꿔요.
3. 저장하고 GitHub에 올리면 끝! 설치한 앱에도 인터넷이 될 때 자동으로 반영돼요.

각 단어에 들어가는 내용: 영어 단어(`english`), 품사(`pos`), 발음기호(`ipa`), 난이도(`level`), 주제(`topic`),
뜻 최대 2개(`meanings`), 예문(`example`), 예문 해석(`exampleKo`), 유의어 1~2개(`synonyms`)

## 새 파일을 만들었을 때만
`sw.js`의 `APP_FILES` 목록에 파일 이름을 넣고, `CACHE_NAME` 숫자를 하나 올려 주세요. (`wordcards-v6` → `wordcards-v7`)
단어 파일이나 `index.html`을 고치기만 할 때는 따로 할 일이 없어요.
